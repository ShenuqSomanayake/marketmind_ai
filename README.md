# MarketMind AI 0.7.0

**The investing journal that grades you.**

Most investors never find out whether their decisions are actually good: they remember the wins and forget the losses.
MarketMind records your theses, predictions and trades *before* outcomes are known, scores them objectively, and gives you a
**report card** that shows your patterns: whether you beat a lazy baseline, chase run-ups, or hold losers longer than winners.
It also warns you when a thesis hits the invalidation price you set. Analysis, backtesting and AI write-ups support that loop,
and every number the AI writes is checked against computed facts.

> **Not financial advice.** MarketMind is a research tool. It is not a broker, does not execute orders, and its
> technical score is a heuristic, not a probability of profit.

## Quick start

Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Create an account on first launch. Data is stored in `marketmind.db` beside `app.py` (override with `MARKETMIND_DB_PATH`).

**Optional, for LLM briefs:** `export ANTHROPIC_API_KEY=...`. Without it, the brief is generated by rules and labelled as such.
**Admin access:** created from the server shell, never by username:

```bash
python -m marketmind.manage grant-admin <username>
```

## What it does

| Page | What you get |
|---|---|
| **Analyse** | Candles, EMA/SMA, Bollinger, volume, Wilder RSI and ATR, MACD. A transparent rule table showing exactly how the 0–100 score is built. Volatility annualised for the actual bar frequency. Unusual-activity flags. A fundamentals screen (losses and negative equity supported). An **AI brief** grounded in a fact sheet you can inspect. |
| **Patterns & levels** (Analyse tab) | Rule-based detection of double tops/bottoms, head & shoulders (and inverse), ascending/descending/symmetrical triangles, support/resistance breakouts and RSI divergences, drawn on the chart with ▲▼ markers. **No hindsight:** the engine walks forward bar by bar and swing points only count once they're confirmed. Each pattern gets a **track record on this asset** (up to 10 years) against the base rate for any day, with a significance test. Also: multi-touch support/resistance and Fibonacci retracements. |
| **Technical readings** (Analyse tab) | ADX/+DI/−DI trend strength, slow stochastic, OBV volume confirmation, rate of change and Bollinger squeeze, each in plain English. |
| **Backtest** | EMA-cross + RSI strategy with configurable parameters, fees **and** slippage. **Buy-and-hold benchmark**, **in-sample / out-of-sample split**, CAGR, Sharpe, Sortino, drawdown, exposure, win rate, and the full trade list. |
| **Portfolio** | Holdings with **live prices, market value, unrealised P&L and weights** (per currency, never FX-mixed). Concentration warning. Watchlist. Correlation, volatility and relative performance fetched automatically, or from uploaded CSVs. |
| **Paper trading** | Per-currency cash accounts. Buys need cash, sells need units (no shorting). Average-cost P&L, realised and unrealised. Price can default to the latest close. |
| **Predictions** | Record Bullish/Neutral/Bearish with a horizon and threshold. **Outcomes are scored automatically from later closes and can't be edited**, so the hit rate isn't self-graded. |
| **Practice** | Real historical charts cut off at a random date. Make your call and it's **scored instantly** from what happened next. Indicators use only pre-cut-off bars, so there's no look-ahead. **Blind mode** hides the ticker and dates and rebases prices to 100, so memory doesn't help. Results build your report card from day one and are kept separate from live calls. |
| **Report card** | **Prediction report card:** hit rate vs an always-bullish baseline, optimism/pessimism bias, chasing after big rises, agreeing vs disagreeing with the technical score, and best timeframe. **Trading habits:** win rate, average win vs loss, and the disposition effect (holding losers longer than winners). **Thesis checker:** each active thesis against its price triggers and review date, plus an optional AI review of what the data supports, contradicts and can't check. Every finding shows its sample size, and nothing is reported under 5 records. |
| **Journal** | Investment theses with required invalidation criteria, optional **price triggers** and review dates (triggered or near-trigger theses and due reviews show on Overview), plus a personal event calendar. |
| **Admin** | Role-gated (hidden from non-admins): account list, record counts, failed-login monitor. User content is not exposed. |

## Running it for other people (beta)

Set these on the host before anyone else signs in:

```bash
export MARKETMIND_FACTUAL_MODE=1      # neutral "5 of 7 rules met" wording; AI describes, never opines
export MARKETMIND_AI_DAILY_LIMIT=10   # per user per day; falls back to rules-based text after that
```

Factual mode is server-wide, so users can't switch it off. Their own predictions, theses and report cards are unaffected.

**Backups and accounts**

- Users: *Settings → Download all my data* (ZIP of CSVs), *Restore from a backup* (password-confirmed, all-or-nothing), and *Delete my account* (removes every record).
- Operator: `python -m marketmind.manage backup` writes a consistent copy to `backups/` while the app runs (schedule it with cron or Task Scheduler). `python -m marketmind.manage reset-password <user>` issues a temporary password and clears the lockout.

## Security model

- PBKDF2-SHA256 (310k iterations) with per-user salts; 12-character minimum; passwords can't contain the username.
- Lockout after 5 failed logins in 15 minutes per username. Unknown usernames still run the hash, so response time doesn't reveal which accounts exist.
- Roles are stored in the database and re-checked on every request; deleting or demoting a user takes effect immediately.
- Every query is parameterised and scoped to the signed-in user's ID.
- Versioned schema migrations upgrade a 0.2.0 database in place.
- AI briefs receive only the computed fact sheet for the asset on screen. A thesis review, which runs only when you click it, also sends that one thesis. Holdings, trades and account data are never sent.

This is still a single-node SQLite app. See `DEPLOYMENT_GUIDE.md` before putting it on the public internet.


## Known limitations

- `yfinance` is unofficial, delayed and not licensed for redistribution. A commercial product needs a licensed feed (`DATA_PROVIDERS.md`).
- The backtest is long-only, single-asset, and fully invested when in a position. Crossovers during the slow-EMA warm-up are ignored.
- No FX conversion: values are reported per currency.
- `sample_demo_ohlcv.csv` is synthetic demo data.
